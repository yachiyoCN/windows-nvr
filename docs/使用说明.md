# 使用说明

本文适用于 Windows 桌面端 1.4.1 和 Android 客户端 1.5.1。录像机以电脑本地时钟作为时间轴基准，摄像头画面中的时间显示不会被修改。

## 首次启动

运行 `录像机.exe`。首次启动不会预置摄像头、账号或远程服务。程序目录中的 `config/` 保存设置，`data/` 保存录像、索引、日志和安全材料，请勿手动删除或复制到公开位置。

## 摄像头与实时预览

在“设备管理”中添加摄像头：

1. 填写名称、主机地址、端口、用户名、密码和视频路径；也可以粘贴完整的 RTSP、RTSPS 或 HTTPS 地址。
2. RTSP 默认使用 TCP，需要时可切换为 UDP。HTTPS 视频源使用自身的证书校验。
3. 保存后点击连接。勾选“启动时自动连接”可在程序启动后自动连接该通道。

录像机最多管理 16 个通道，支持单画面、四分屏、九分屏和分页查看。双击画面可放大，再次双击恢复；单画面可进入视频全屏。切换预览或回放不会停止后台录像。

## 画质和时间水印

在“录像机设置 → 当前摄像头”中选择“自动 · 最高可用”、4K、1440p、1080p、720p 或 480p。自动模式会使用摄像头实际可连接的最高画质，手动选项作为分辨率上限。设置只影响实时画面和新录像，已有录像保持原画质。

“录像时间水印”按通道单独设置，默认关闭。开启后，电脑时间会写入之后生成的录像；摄像头已经显示时间时可保持关闭。切换水印会先完成当前片段，再使用新设置录制。

## 录像和存储

“录像机设置 → 存储”是所有通道共用的设置：保存目录、最大占用空间、保留天数和启动时是否自动录制。保存目录必须位于本机真实目录，不能使用目录联接或与程序目录嵌套。

顶部的“全部开始录像”和“全部停止录像”控制所有已配置通道；单个通道也可独立启停。摄像头暂时断开时，录像状态会保留并等待重连，已写入的片段不会因等待连接而丢失。恢复连接后会继续生成新的片段。

存储达到空间上限或超过保留天数时，程序按时间删除最旧的非锁定录像。正在播放、下载或等待索引的文件会暂时保留。变更保存目录不会移动旧录像。

## 回放和事件时间轴

打开“回放”后选择通道、日期或时间区间。时间轴可连续拖动并通过滚轮缩放，支持跨片段播放、前后 10 秒、上一段、下一段、精确定位和 0.5～8 倍速。活动录像在已有可读数据后即可播放，片段结束时会等待后续数据。

时间轴颜色含义：

- 蓝色：存在录像数据
- 橙色：已生成的人员事件
- 中心红线：当前播放位置

人员检测在录像机本地运行，结果会受到光线、遮挡、目标大小、运动模糊和取样间隔影响。事件标记用于辅助检索，不应作为唯一的安全判断依据。录像尚未完成分析时，空事件列表不代表确认无人。

## 远程访问

“远程访问”分别管理 Web 服务和 App API：

- Web 默认端口 8079
- App API 默认端口 9079

服务默认关闭。启用后创建管理员和普通用户，并为普通用户分配可查看的通道。Web 和 App API 共用录像机的用户权限，但登录会话相互独立。

### HTTPS 配对

首次连接时，在录像机的“加密连接”页面查看证书公钥指纹。Android 客户端输入 `https://主机地址:9079`，Web 客户端访问 `https://主机地址:8079`，并核对指纹或受信任证书。指纹变化、证书过期或主机名不匹配时应停止连接并检查服务器，不要关闭证书验证。

外网访问建议使用 VPN 或可信 HTTPS 反向代理。若使用路由器端口映射，9079 转发到 App API，8079 转发到 Web 服务，并在防火墙中只放行必要来源。公网域名必须与证书名称一致。

### 登录保持

登录时启用“保持登录，自动续期”，客户端会使用 Android Keystore 或浏览器安全存储保存加密会话，不保存明文密码。访问会话约 15 分钟，续期会话每次成功续期后有效 30 天。长期离线、管理员撤销账号或服务端关闭后需要重新登录。

## Web 查看

Web 控制台提供实时预览、分屏切换、抓图、回放、时间筛选、事件筛选、倍速和录像下载。实时预览会根据网络状况降低帧率，电脑端录制不受影响。下载操作取得的是当前位置所在的单个原始录像片段，不会把整个查询区间合并成一个文件。

## Android 客户端

Android 客户端使用“设备”和“我的”两个主入口。设备页显示已授权通道，进入通道后可在实时预览与回放之间切换；回放页支持日期、区间、事件筛选、连续时间轴、拖动定位、倍速和视频全屏。后台时会释放实时连接，返回后恢复页面位置，电脑端录像继续运行。

在“我的 → 外观”中选择跟随系统、浅色或深色模式。全屏时返回键先退出视频全屏，再返回上一级页面。更新 App 时直接覆盖安装同包名且同签名的新版本，不要卸载旧版本或清除数据。

## 支持的 HTTPS 视频源

使用 HTTPS 视频源时，在设备管理中粘贴完整视频地址，例如：

```text
https://HOST:PORT/video/h264
https://HOST:PORT/video/mjpeg
```

认证信息应通过设备管理界面填写；地址中的特殊字符需要进行 URL 编码。RTSP/RTSPS 是首选视频协议。自签名 HTTPS 设备需要先建立受信配对，未配对或证书发生变化时连接会被拒绝。

## 更新和备份

### Windows 覆盖更新

1. 将更新包解压到新的空目录，保持包内结构。
2. 双击 `更新.cmd`，或把已有程序目录拖到该文件上。
3. 等待程序正常退出、录像保存和更新工具完成校验。

更新工具会备份现有发布文件，只替换程序、运行环境、公共依赖和 App 安装包。`config/`、`data/`、用户、设备配对、存储规则和录像目录会保留。不要使用会删除目标目录多余文件的镜像同步工具。

### 数据备份

备份时关闭录像机，然后保存整个 `config/` 和 `data/`，并保留原始录像目录。`data/remote-security/`、`data/camera-security/` 和签名材料含私密密钥，只能存放在受控位置。恢复到其他电脑时，应先恢复目录权限，再启动程序。

## 常见问题

| 现象 | 检查项目 |
| --- | --- |
| 连接等待 | 摄像头服务、地址、端口、防火墙和局域网可达性 |
| 画面能看但不能录像 | 存储目录权限、可用空间和 FFmpeg 文件 |
| 手机无法登录 | API 服务开关、9079 转发、证书指纹、系统日期 |
| Web 无法打开 | Web 服务开关、8079 转发、证书和浏览器代理 |
| 人员事件缺失 | 光线、遮挡、目标大小、模型依赖和分析是否完成 |
| 更新失败 | 关闭旧程序、保留备份目录、检查更新清单和磁盘空间 |
